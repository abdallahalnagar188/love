# 🎵 Background Music Folder

Place your custom romantic or birthday song here named:
`song.mp3`

### Path:
`assets/music/song.mp3`

### Note on Audio Autoplay:
1. When `assets/music/song.mp3` exists, the web application will automatically play it when the recipient opens the interactive 3D gift box on the splash screen!
2. If `song.mp3` is not present, the app has a built-in romantic acoustic piano stream fallback so the music experience will **never fail or stay silent**!
3. You can also configure external direct MP3 links inside `js/config.js` under `music.fallbackSongUrl`.
