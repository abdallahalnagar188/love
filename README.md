# 💖 Romantic Interactive Birthday & Love Story Web App

تطبيق وموقع ويب سينمائي تفاعلي متكامل للاحتفال بعيد ميلاد الحبيبة واستعراض قصة الحب والذكريات، جاهز للنشر الفوري والمجاني بنقرة واحدة على **Vercel** دون الحاجة لأي بناء (Zero-Build CDN Stack).

## 🌟 المميزات والمؤثرات التفاعلية (Features)

1. **🎁 شاشة فتح الهدية التفاعلية ثلاثية الأبعاد (Interactive 3D Gift Box):**
   - صندوق هدايا مضيء مع شريط وفيونكة متحركة ثلاثية الأبعاد.
   - حل عملي لمشكلة حظر تشغيل الصوت التلقائي في المتصفحات (Autoplay Policy): بمجرد الضغط لفتح الهدية، يبدأ عزف الموسيقى فوراً، وينطلق انفجار من القلوب والكونفيتي، وتتلاشى الشاشة بسلاسة سينمائية عبر GSAP.

2. **✨ نظام جزيئات القلوب المتصاعدة في الخلفية (Canvas Particle System):**
   - محرك رسومي خفيف وسريع على HTML5 Canvas يرسم قلوباً وومضات متلألئة تتصاعد وتتمايل بنعومة مع حركة الشاشة.
   - يدعم التفاعل اللمسي (توليد قلوب إضافية عند لمس الشاشة).
   - موفر للبطارية ويتوقف تلقائياً عند مغادرة الصفحة (`visibilitychange`).

3. **🎵 مشغل موسيقى عائم بتصميم زجاجي (Floating Glassmorphic Audio Player):**
   - أسطوانة فينيل تدور مع تشغيل الأغنية، وأعمدة مرئية (Soundwave Equalizer) تتراقص مع الإيقاع.
   - أزرار تشغيل/إيقاف مؤقت، وكتم صوت.
   - يدعم مسار الأغنية المحلي `assets/music/song.mp3` مع تبديل تلقائي فوري لرابط صوتي رومانسي بديل إذا لم يكن الملف المحلي موجوداً لضمان عدم توقف الموسيقى أبداً!

4. **👑 قسم البداية والاحتفال (Hero Celebration):**
   - ترويسة متوهجة باسم الحبيبة.
   - تأثير الآلة الكاتبة (Typewriter Effect) يستعرض أجمل العبارات والتهاني الرومانسية بسلاسة.
   - عداد رقمي مباشر وحي (Live Counter) يحسب باليوم والساعة والدقيقة والثانية الوقت منذ بداية القصة أو تاريخ اللقاء.

5. **🎬 شريط الذكريات السينمائي (Cinematic Reel with Ken Burns Effect):**
   - مشغل فيديو سينمائي مخصص يتنقل بين الصور بتأثير التقريب والحركة البطيئة (Ken Burns Montage).
   - شريط ترجمة سفلية متحرك يعرض قصة وتاريخ ومكان كل صورة.
   - أزرار تحكم وشريط تقدم وميزة ملء الشاشة.

6. **📸 ألبوم البولارويد التفاعلي (Interactive Polaroid Grid):**
   - بطاقات صور بنمط كاميرا البولارويد الكلاسيكية مع ميلان طبيعي وظلال ثلاثية الأبعاد.
   - عند تمرير الفأرة تستقيم البطاقة وتتوهج، وعند النقر يفتح معرض مكبر (Lightbox Modal) لقراءة الذكرى كاملة.

7. **🌟 خط زمني تفاعلي للذكريات (Interactive Glowing Timeline):**
   - مسار عمودي متوهج يربط المحطات المهمة.
   - تظهر البطاقات بتأثير التمرير التدريجي عبر GSAP ScrollTrigger.

8. **💌 ظرف رسالة الحب ثلاثي الأبعاد (Interactive Love Letter):**
   - ظرف هدايا تفاعلي بختم شمعي ذهبي ينفتح بنعومة ثلاثية الأبعاد ليكشف عن رسالة حب خاصة مكتوبة من القلب.

9. **🎂 كيكة عيد الميلاد وإطفاء الشموع (Make a Wish Birthday Cake Finale):**
   - كيكة تفاعلية بشمعة مضيئة بلهب متذبذب حقيقي.
   - زر تفاعلي: *"اطفي الشمعة واتمني أمنية"*.
   - عند الضغط ينطفئ اللهب ويتصاعد الدخان، وتنطلق ألعاب نارية وكونفيتي مبهرة على كامل الشاشة، مع نافذة سرية تكشف عن أمنية ورسالة حب خاصة!

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Semantic HTML5 & Modern CSS3** (Animations, 3D Transforms, Keyframes)
- **Tailwind CSS (via CDN)**
- **GSAP 3.12.5 & ScrollTrigger (via CDN)**
- **canvas-confetti (via CDN)**
- **Web Audio API** لإنتاج نغمات ساحرة متوافقة مع كل المتصفحات
- **Google Fonts** (`Cairo`, `Tajawal`, `Dancing Script`, `Plus Jakarta Sans`)
- **FontAwesome 6 (via CDN)**

## ⚙️ طريقة التخصيص السريعة (Customization)

كل النصوص والتواريخ والصور والموسيقى موجودة في ملف واحد فقط:
👉 `js/config.js`

افتح الملف وعدّل الحقول التالية كما تحب:

```javascript
window.LOVE_CONFIG = {
  // 1. بيانات الحبيبة والاسم
  recipient: {
    name: "نـور",
    nickname: "حبيبتي وأميرتي 👑❤️",
    heroBadge: "اليوم يوم مميز جداً في قلبي ✨"
  },

  // 2. الاتجاه واللغة (rtl للعربية أو ltr للإنجليزية)
  direction: "rtl",

  // 3. تاريخ بداية القصة أو الذكرى الخاصة للعداد
  specialDate: "2023-09-14T20:00:00",

  // 4. الموسيقى
  music: {
    localSongPath: "assets/music/song.mp3",
    songTitle: "Until I Found You",
    artistName: "أجمل نغمة لعيونك ❤️"
  },

  // 5. عبارات الآلة الكاتبة
  typewriterPhrases: [
    "كل عام وأنتِ الخير لكل عام.. 🌸",
    "في مثل هذا اليوم وُلدت سعادتي.. ✨"
  ],

  // 6. صور شريط السينما ومعرض البولارويد
  photos: [
    {
      src: "assets/images/photo1.jpg", // أو رابط خارجي من Imgur / Unsplash
      title: "أول نظرة.. وبداية كل شيء",
      caption: "في اليوم الذي التقت فيه أعيننا لأول مرة...",
      date: "سبتمبر 2023",
      location: "أول لقاء ☕",
      rotation: "-2deg"
    }
  ],

  // 7. محطات الخط الزمني
  timelineMilestones: [...],

  // 8. نص رسالة الحب والختام
  loveLetter: {...},

  // 9. كيكة عيد الميلاد والأمنية السرية
  cakeSection: {...}
};
```

## 🚀 النشر المباشر على Vercel (Deployment)

### الطريقة الأولى: عبر لوحة تحكم Vercel (الأسهل والأسرع)
1. ارفع المشروع إلى حسابك على **GitHub** أو **GitLab**.
2. سجّل الدخول إلى [vercel.com](https://vercel.com).
3. اضغط على **Add New Project** واختر المستودع (Repository).
4. اضغط **Deploy** مباشرة (لا يحتاج أي إعدادات Build لأن المشروع Zero-Build جاهز).
5. خلال 5 ثوانٍ ستحصل على رابط مباشر ورسمي تشاركه مع شريكة حياتك!

### الطريقة الثانية: عبر Vercel CLI في سطر الأوامر
```bash
# تثبيت أداة Vercel إذا لم تكن مثبتة
npm install -g vercel

# النشر الفوري
vercel
```
